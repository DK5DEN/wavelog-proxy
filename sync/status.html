Abweichungen (Edits)

Feld-Änderungen mit eindeutiger Richtung werden automatisch auf die andere Seite übertragen; Konflikte und nicht per API änderbare Felder bleiben hier zur manuellen Entscheidung. Erkannte Löschungen werden erst nach Bestätigung ausgeführt. Richtung stammt aus dem Vergleich mit der letzten Prüfung.

Server-URL
Server-API-Token (APIv2, wl2_… — Scopes qso:read/write/delete, station:read/write, confirmation:read, optional statistic:read)
Server-Legacy-Key (v1, optional — nur für den Versionsabgleich, falls das Token keine Admin-Rechte hat)
Lokales API-Token (wird automatisch erstellt)

Stationen im Sync

–
Abgewählte Server-Stationen werden nicht gesynct und beim nächsten Sync lokal samt QSOs entfernt (der Server bleibt unberührt). Neue Stationen am Server sind automatisch angewählt. Gilt nach „Speichern & testen".

Was wird gesynct?

Reparatur

Setzt dieses Profil lokal auf den Stand des Servers zurück: alle lokal gespeicherten QSOs, Contest-Sessions und Stationen des Profils werden gelöscht und frisch vom Server geladen. Ungesyncte lokale QSOs gehen dabei verloren!
